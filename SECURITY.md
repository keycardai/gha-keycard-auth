# Security Policy

## Reporting Security Issues

Keycard Labs takes security seriously and encourages you to report any
vulnerability promptly so that appropriate action can be taken.

To report a security issue in `gha-keycard-auth`, email
**security@keycard.ai**. Please **do not** open a public GitHub issue for
vulnerabilities.

## Responsible Disclosure

We appreciate the efforts of security researchers and individuals who help us
maintain the security of our open source projects. If you believe you have
found a security vulnerability, please adhere to responsible disclosure
practices by allowing us a reasonable amount of time to investigate and
address the issue before making any information public.

## Supported Versions

This action is on the `0.x` release line. Only the most recent `0.x` minor
version receives security fixes. Once `1.0.0` ships, the supported-versions
policy will be revised here.

## Service-Related Security Issues

If you encounter security issues that are not directly related to this action
but pertain to the Keycard service itself, please email **security@keycard.ai**
and note that the report concerns the service rather than this repository.

## Terms and Policies

For questions or concerns regarding Keycard's terms of service or security
policies for the broader Keycard platform, contact **support@keycard.ai**.

---

Thank you for helping keep `gha-keycard-auth` and the systems it interacts
with secure.
